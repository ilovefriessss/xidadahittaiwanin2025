————————————ai生成的介绍
它结合了**粉色蒸汽波美学**、**地雷系少女风格**以及**政治讽刺迷因**，包含一个内置的 Galgame（文字冒险游戏）。

## ✨ 特性 (Features)

*   **沉浸式视觉体验**：CRT 扫描线特效、Windows 95 复古弹窗、霓虹粉紫配色。
*   **交互式 Galgame 引擎**：
    *   由原生 JS 驱动的轻量级 AVG 引擎。
    *   打字机文本效果与复古 8-bit 音效合成。
    *   多分支剧情：包含 Happy End, Bad End 以及隐藏的 True End。
*   **彩蛋系统**：
    *   DVD 碰撞屏幕保护程序（作为 True End 触发器）。
    *   逼真的伪装系统警告界面。
*   **响应式设计**：适配桌面端与移动端浏览。
